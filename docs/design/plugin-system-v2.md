# 插件系统重构设计

状态：已接入主界面。插件逻辑采用 Worker 内的 QuickJS，界面由宿主按声明式节点渲染；原生命令需重启开发版后加载。

## 1. 完整设计树

```text
Markart 插件系统
├─ 插件与生命周期
│  ├─ manifest.json + 编译后的 main.js；开发时可使用 TypeScript
│  ├─ activate(api) 启用，deactivate() 停用
│  ├─ 注册与监听返回 Dispose，资源按插件、面板、渲染任务分层回收
│  ├─ 停用：取消任务、注销接口、销毁视图，保留私有数据
│  └─ 卸载：删除代码、清理运行权限；默认保留私有数据，可选择清除
├─ 隔离与权限
│  ├─ 插件仅通过 PluginAPI 通信，不接触 CM6、宿主 DOM 或内部数据库
│  ├─ 插件逻辑在可终止的隔离运行时执行
│  ├─ 自绘界面在隔离视图内运行，宿主拥有外部容器
│  ├─ 清单声明能力、网络域名及局域网/本地服务地址与端口
│  └─ 不提供启动本地程序的接口，不沿用旧插件兼容层
├─ 界面架构
│  ├─ 左右侧栏各分上下两区，共四个固定区域
│  ├─ 每区容纳多个面板，点击名称切换，每次显示一个
│  ├─ 内置文件、大纲与插件面板使用同一套容器
│  ├─ 面板可移到任一区域；上下高度及侧栏宽度可调并保存
│  └─ 空区自动收起，移入面板后恢复原比例；不新增任意独立侧栏
├─ 文件与内容
│  ├─ 文件访问限定于当前文件夹及已打开页签所属目录，切换时无需确认
│  ├─ 文本、附件、Frontmatter 分别提供接口
│  ├─ 已打开文件经版本检查与可撤销编辑事务修改
│  ├─ 文件操作统一更新链接、SQLite 索引、页签路径与文件监听
│  ├─ SQLite 索引提供文件、元数据、链接等查询，不暴露数据库连接
│  └─ 渲染扩展与导出处理操作内容快照，不绕过编辑器保存保护
└─ 扩展能力
   ├─ 命令、快捷键、通知、固定菜单与偏好设置
   ├─ 编辑器全文、选区、光标、模式、事务、补全、装饰与诊断
   ├─ Markdown 块/行内渲染扩展，适配实时渲染
   ├─ 导出前处理、AST 转换、新格式及预览
   └─ 插件私有储存、后台任务与清单范围内的网络请求
```

## 2. 侧栏规则

### 布局

```text
┌──────────────┬──────────────────────┬──────────────┐
│ 左侧上方      │                      │ 右侧上方      │
│ 文件 / 面板 A │                      │ 面板 C / D   │
├──────────────┤        编辑区         ├──────────────┤
│ 左侧下方      │                      │ 右侧下方      │
│ 大纲 / 面板 B │                      │ 面板 E / F   │
└──────────────┴──────────────────────┴──────────────┘
```

| 规则 | 行为 |
| --- | --- |
| 默认布局 | 文件在左上，大纲在左下；右侧按需打开，不内置示例功能 |
| 区内切换 | 使用轻量名称按钮，与确认的预览一致，不使用卡片式页签 |
| 移动 | 在管理侧栏弹窗中拖到目标区域；移动后显示目标面板 |
| 空区 | 同侧仅剩一个非空区域时占满高度；同侧全空时通过统一管理入口添加 |
| 尺寸 | 左右各自保存上下比例；收起空区不覆盖原比例；横向尺寸受编辑区最小宽度限制 |
| 添加与关闭 | 中央列表展示未放置视图；拖回中央关闭实例，不停用整个插件 |
| 视图数量 | `View` 是注册的视图类型，`SidebarItem` 是打开的实例，`SidebarGroup` 是承载实例的容器；默认每类型单实例，可声明多实例 |
| 状态 | 首次可见时加载界面；切换保留状态、暂停不可见渲染；移动保留实例身份与状态；关闭销毁界面实例 |
| 目录 | 面板默认跟随活动目录，可固定目录；后台任务绑定启动时的目录 |
| 持久化 | 宿主保存面板位置、顺序、选中项、尺寸与可序列化状态；不保存 DOM |

左右侧栏的开关保留现有位置。现有菜单、文件页签、编辑器与状态栏继续使用原有结构。旧的插件库及所有功能块均分高度机制由侧栏面板管理取代。

### 容器边界

宿主控制标题、切换入口、菜单、尺寸、分割线与主题外观。插件仅绘制面板内容。通用交互使用宿主控件；图形、聊天或画布可在隔离视图内部自绘。

公共颜色、字体与间距以受控主题令牌传入隔离视图。插件样式不注入宿主全局；主题仍由宿主控制外框，并向插件内容提供变量。

## 3. PluginAPI 模块

以下为建议命名与职责，不代表当前接口已存在。最终方法签名在实现前固化到 SDK。

| 模块 | 提议接口 | 职责 |
| --- | --- | --- |
| `commands` | `register`、`execute`、`list` | 注册命令与默认快捷键；冲突检测与用户覆盖由宿主管理 |
| `editor` | `getSnapshot`、`applyEdits`、`transaction`、`getSelection`、`setSelection`、`getCursor`、`setCursor`、`getMode`、`onChange` | 读取全文与版本，事务修改、选区、光标、编辑模式、变更监听 |
| `editor.extensions` | `registerCompletionProvider`、`registerDecorationProvider`、`registerDiagnosticProvider` | 输入候选、文本装饰、诊断与修复；不暴露 CM6 |
| `files` | `list`、`get`、`open`、`create`、`mkdir`、`move`、`rename`、`trash`、`readText`、`writeText`、`readBytes`、`writeBytes`、`readFrontmatter`、`updateFrontmatter`、`watch` | 对已打开目录中的文件操作；调用宿主文件服务，统一处理链接、索引和页签 |
| `index` | `files`、`content`、`metadata`、`links`、`tagged`、`subscribe` | 复用 Rust 管理的 SQLite 基础索引；查询限定于当前文件夹及已打开页签所属目录 |
| `markdown` | `registerBlockRenderer`、`registerInlineRenderer` | 注册渲染器；传递可序列化语法节点、源码范围与更新信息 |
| `exports` | `beforeExport`、`transformAst`、`registerFormat` | 拦截导出、转换 AST、添加格式与预览 |
| `ui` | `registerAction`、`openDialog`、`notify`、`prompt` | 固定入口、小窗、居中弹窗与通知 |
| `ui.sidebar` | `register`、`open`、`getItem`、`listItems`、`listGroups` | 注册 View 类型，创建与查询 SidebarItem、SidebarGroup；实例提供 `reveal`、`moveTo`、`close` |
| `settings` | `registerCategory`、`registerControl` | 偏好设置分类、文本/密码/多行输入、数字、下拉、切换块、开关与按钮 |
| `clipboard` | `readText`、`writeText` | 经剪贴板权限访问；隔离视图使用同一宿主接口 |
| `network` | `request` | 经宿主校验清单声明后发出请求；本地服务需单独声明地址 |
| `storage` | `get`、`set`、`remove` | 插件命名空间中的私有数据 |
| `events` | `on`、`whenReady` | 文件打开、保存、目录切换、选区、主题、布局与索引就绪等事件 |
| `app` | `version`、`apiVersion`、`supports` | 查询宿主版本、API 协议版本及可用能力 |
| `lifecycle` | `signal`、`track`、`setTimeout`、`setInterval` | 取消信号、资源回收与受管理定时器 |

快捷键属于命令定义，不另外维护一套可绕过冲突检测的键盘监听接口。面板属于 `ui.sidebar`，不是任意布局编辑 API。

### 固定界面入口

```ts
type ActionLocation =
  | 'file-tree'
  | 'topbar-menu'
  | 'tab'
  | 'tab-context'
  | 'format-toolbar'
  | 'slash'

type SidebarGroupId = string // 宿主生成的不透明标识

type SidebarItem = {
  readonly id: string
  readonly viewId: string
  getInfo(): Promise<{ groupId: SidebarGroupId }>
  reveal(): Promise<void>
  moveTo(groupId: SidebarGroupId): Promise<void>
  close(): Promise<void>
}
```

命令自动进入命令工具。`topbar-menu` 项可由用户固定到顶部图标区，不单独注册第二种顶部按钮。偏好设置和快捷键使用专属模块注册。

### 面板接口边界

`register()` 注册 View 类型，`open()` 创建或选中 SidebarItem，`listGroups()` 返回当前可用的 SidebarGroup。一个 Group 可以容纳多个 Item，同一时间显示其中一个。Item ID 在移动、隐藏与恢复时保持稳定；关闭后重新打开会创建新实例 ID。

```ts
api.ui.sidebar.register({ id: 'graph', /* 视图定义 */ })
const item = await api.ui.sidebar.open('graph')
const groups = await api.ui.sidebar.listGroups()
await item.moveTo(groups[0].id)
```

注册不要求指定方位，也不会自动创建实例或展开侧栏。容器 ID 由宿主管理，插件不得拼接方位字符串。宿主为四个固定区域维护稳定的容器身份，即使空区收起，仍可作为移动目标。

| 放置来源 | 规则 |
| --- | --- |
| 从管理侧栏弹窗添加 | 进入用户操作的 Group |
| 恢复布局或重新打开 | 优先恢复用户保存的位置 |
| 首次程序打开 | 可传入从 `listGroups()` 获取的 Group ID；省略时由宿主安排，初始策略为右上区 |
| 已有单实例 | 选中并显示已有 Item；不因再次打开改变用户位置 |
| 程序移动 | `moveTo(groupId)` 明确移动自己的实例，并显示目标区域 |

### 视图与实例生命周期

| 通知/方法 | 用途 |
| --- | --- |
| `onOpen` / `onClose` | 实例资源的创建与销毁 |
| `onShow` / `onHide` | 恢复或暂停可见界面渲染 |
| `onResize` | 接收容器有效尺寸；连续变化合并通知 |
| `onContextChange` | 接收活动文件、目录、权限或固定目录变化 |
| `getState` / `setState` | 保存与恢复可序列化状态 |
| `migrateState` | 按视图状态版本升级旧状态 |

先恢复状态与上下文，再显示视图。异步打开未完成就关闭时，取消初始化，不再显示过期结果。资源以插件、SidebarItem、Markdown 渲染任务、弹窗为独立作用域；关闭子作用域时仅回收其资源，插件停用时递归回收全部作用域。

隐藏视图暂停绘制，不自动启动后台任务。首次不可见实例可只恢复状态、延迟加载界面。状态恢复失败仅重置该实例状态并报告原因，不阻止宿主启动。升级前保留原始状态，迁移成功后再替换。

### 隔离界面协议

界面使用宿主控件描述或插件包内的隔离视图入口，不向插件传递宿主 `HTMLElement`。构建模板包含逻辑入口 `main.js`、可选视图入口、局部样式与资源；视图入口在清单中声明，由宿主解析。

| 项目 | 约定 |
| --- | --- |
| 资源 | 只加载插件包内声明的资源与目录范围内的文件资源；资源 URL 由宿主生成，关闭实例后释放 |
| 消息桥 | SDK 封装请求、响应、事件、取消和错误；校验插件身份、实例身份、参数和清单声明 |
| 主题 | 注入颜色、字体、间距令牌及变更事件；插件样式仅作用于自身视图 |
| 焦点 | 内容接收普通输入；应用快捷键由宿主统一仲裁；关闭弹窗后返回触发位置 |
| 菜单与弹窗 | 通过宿主 API 请求，不自行覆盖宿主界面；锚点坐标由桥接层转换与校验 |
| 剪贴板与网络 | 使用宿主代理接口；隔离视图不能绕过权限直接调用原生桥或网络 |

实际隔离容器及安全策略经原型验证后确定。SDK 提供统一视图通信层，插件无需自行编写消息桥。

### 受控编辑扩展

补全、装饰、诊断与事务均纳入本次设计。接口接收可序列化的编辑上下文与版本，不接受 CM6 实例、扩展对象或宿主 DOM。

| 接口 | 返回内容与规则 |
| --- | --- |
| `registerCompletionProvider` | 返回候选文本、标签、替换范围与排序信息；支持异步查询及取消，宿主绘制候选列表 |
| `registerDecorationProvider` | 返回版本对应的文本范围和宿主认可的装饰类型；禁止任意 CSS/HTML 注入 |
| `registerDiagnosticProvider` | 返回范围、严重程度、消息与可选修复编辑；应用修复时重新校验版本 |
| `transaction` | 对明确文件版本提交一组编辑及可选选区变更；整组校验，通过后形成一次撤销记录 |

输入后异步调度扩展，不阻塞输入线程。连续变更取消过期请求，丢弃旧版本结果；候选数、装饰数和单次处理时间有宿主限制。中文输入法组合期间不强制替换文本或提交候选。只读模式下不接受修复及事务写入。

实时 Markdown 渲染同样使用版本、取消信号与可见范围，不在每次按键时同步等待插件返回。渲染超时或结果失效时使用宿主回退显示；原始 Markdown 保持可编辑。导出渲染采用明确等待与失败策略，不复用交互渲染的静默回退。

## 4. 数据、权限与故障规则

| 事项 | 约定 |
| --- | --- |
| 权限说明 | 本地插件列表展示清单能力与网络地址；启用时自动提供已声明权限，无独立授权及撤销按钮 |
| 文件范围 | 使用宿主已打开目录与相对路径；宿主校验路径、真实路径与符号链接，防止越界 |
| 多目录页签 | 活动文件与活动目录作为明确上下文；文件访问范围跟随已打开目录，无需逐目录授权 |
| 文件身份 | 稳定文件 ID 与目录标识共同定位；重命名和同目录移动保留 ID；复制产生新 ID；删除后句柄失效。跨目录移动返回宿主确认后的目标身份，不假设 ID 不变 |
| 文件操作 | 新建、移动、重命名、回收站删除及打开均调用宿主服务；维护相关链接、索引、页签及监听事件。失败返回明确状态，不报告未完成的链接更新 |
| 文件修改 | 打开中的文件经编辑器版本检查与撤销事务处理；文件 API 不直接覆盖缓冲区；未打开文件通过宿主版本校验后写入，Frontmatter 更新使用相同保护 |
| 外部修改设置 | 保留现有自动加载/确认策略，用于真实外部变更；不作为插件写权限 |
| 网络 | 域名与本地服务分别声明；跳转目标重新校验；停用取消相关请求 |
| 后台任务 | 显式声明，绑定启动目录；停用、撤权或销毁时取消并回收 |
| Markdown | 优先标准 Markdown 载体；非标准语法明确声明，不擅自改写原文件 |
| 内置渲染覆盖 | 默认只增加渲染器；覆盖内置语法由用户选择，同一语法选定一个替代渲染器 |
| 导出 | 对快照/AST 副本操作；新格式进入现有导出弹窗，有预览则展示，否则说明格式 |
| 导出保存 | 宿主保存到用户选定路径，不因此授予插件任意文件写权限 |
| 导出失败 | 中止本次导出并标明插件；用户可明确选择跳过后重试，不静默输出不完整结果 |
| 正常错误 | 网络失败、拒绝权限、版本过期返回结构化错误，不停用插件 |
| 故障 | 未捕获异常、执行超时或运行时崩溃终止该插件，持久化故障停用状态 |
| 资源回收 | 监听、定时器、视图、请求、任务均归插件资源域；停用统一清理，清理过程受超时限制 |

## 5. SDK 与宿主代码划分

API 公开定义集中在 SDK 目录；宿主实现按模块分开。开发者不需要读取宿主内部代码。

```text
src/plugins/
├─ sdk/                 公开类型、错误与协议；通过统一入口导出
├─ runtime/             隔离运行时、消息桥、超时、插件会话
├─ permissions/         清单能力、目录边界与网络校验
├─ host/                editor、files、index、markdown、exports 等适配器
└─ ui/                  侧栏容器、控件、隔离视图与布局持久化
```

保留 `activate` / `deactivate` 入口，提供 TypeScript 类型与构建模板。没有旧插件迁移要求，不为旧 API 保留兼容层。

### 版本、就绪与错误契约

| 项目 | 约定 |
| --- | --- |
| 清单 | 定义清单版本、API 兼容范围、最低宿主版本、入口资源及必需/可选权限；不支持的必需能力阻止启用并指出原因 |
| 能力查询 | `app.supports()` 查询可用 API 能力；查询结果不代表插件已声明对应权限 |
| 就绪阶段 | 区分宿主就绪、布局恢复与指定目录索引就绪；`whenReady()` 已就绪时立即完成，等待支持取消 |
| 索引一致性 | 返回目录、索引版本/游标和就绪状态；文件保存完成不等同索引已更新，插件可等待对应更新 |
| 事件上下文 | 事件包含来源、目录、文件 ID 与版本；文件事件和索引事件分开，避免误认触发顺序 |
| 错误 | 统一错误码区分权限或访问范围不符、文件不存在、只读、版本冲突、取消、超时、宿主未就绪及插件故障；包含可定位上下文 |
| 异步调用 | 跨隔离边界的请求以 Promise 返回，使用请求 ID、取消信号和作用域；关闭后丢弃过期响应 |
| 调试 | 日志带插件 ID、实例 ID 与请求 ID；开发构建支持 source map，定位到 TypeScript 源码；日志默认不记录文件正文、凭据或请求敏感内容 |
| 状态兼容 | 插件数据、面板状态与 API 协议分别版本化；迁移失败保留原数据，提供错误与恢复入口 |

### 验证后确定的技术项


| 项目 | 验收要求 |
| --- | --- |
| 逻辑运行时 | 插件死循环时编辑器仍可输入；宿主可终止插件 |
| 内存边界 | 大量分配内存时验证实际故障范围；不能把 Worker 当成独立进程级内存隔离 |
| 自绘界面 | 不可访问宿主 DOM、Tauri 全局桥或未声明网络；视图内部卡死不能拖死编辑器 |
| 清理 | 反复启停、开关面板后不累积事件、任务、定时器与隔离视图 |
| 编辑保护 | 版本冲突、只读、多个目录、未保存文件均不被绕过；事务失败不产生部分修改 |
| 编辑扩展 | 快速输入、中文输入法、取消与过期结果不干扰正文；大量装饰与诊断不阻塞输入 |
| 文件一致性 | 移动/重命名后链接、页签与索引最终一致；失败时可追踪已完成和待恢复阶段 |
| 恢复与兼容 | 侧栏空区恢复、多实例状态迁移、插件缺失及索引未就绪均不阻止启动 |

实现采用独立 Worker 内的 QuickJS，JavaScript 堆上限 32 MB，执行轮次有超时中断。插件界面通过 UiNode 描述，由宿主在封闭 Shadow DOM 中创建；插件无法执行界面脚本或取得宿主 DOM。网络请求由 Rust 校验清单声明的来源，单次请求上限 30 秒。

## 侧栏管理交互

统一从右上角“偏好设置 → 布局”打开弹窗。左上、左下、右上、右下对应四个面板组，中央是未放置面板列表。拖入放置、组内排序、拖回中央关闭；不提供点击放置、选中状态、计数和各组操作按钮。拖动时禁止选择文字，结束或取消后恢复。
