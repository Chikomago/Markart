# 文件索引性能验证

2026-10-24，macOS 本地临时目录，Rust debug 构建。测试通过 `file_index::tests::ten_thousand_files_performance` 重现。

## 数据集

10,000 个 Markdown 文件，分布在 20 个目录。每个文件包含 YAML 标签、标题、中文正文和一个本地链接；总内容 12,652,653 字节（约 12.1 MiB）。

## 实测

| 项目 | 耗时 |
| --- | ---: |
| 首次建库 | 6.21 秒 |
| 重开并核对内容 | 2.21 秒 |
| 唯一关键词查询，返回 1 项 | 0.59 毫秒 |
| 中文短词查询，返回 10,000 项 | 61.15 毫秒 |
| 文件名补全，返回 1 项 | 47.61 毫秒 |
| 文件元数据分页，500 项 | 19.69 毫秒 |
| 单文件修改并更新索引 | 0.82 毫秒 |
| 链接关系分页，500 项 | 51.35 毫秒 |

缓存文件合计 76,468,280 字节（约 72.9 MiB），包含 WAL、SHM，未压缩整理。测试进程峰值 RSS 为 28,393,472 字节（约 27.1 MiB）；不包含桌面界面、WebView 或插件，不能当作应用总内存。

## 发现与修复

首次测量的建库耗时为 53.4 秒。新文件逐条执行旧关联清理，标题表按来源删除时还会扫描全表，随文件数增加而放大开销。

现在仅对已有文件清理旧关联，标题和标签按来源建立索引，并复用热点 SQL 语句。查询计划测试防止按来源清理退回全表扫描。打开文件夹和首次建库命令在后台任务执行；打开结果仍等待核对完成。

## 重现

```sh
cargo test --manifest-path src-tauri/Cargo.toml --offline --lib \
  file_index::tests::ten_thousand_files_performance -- --ignored --nocapture
```

测试使用独立临时目录，结束后删除测试数据。常规测试另覆盖目录范围、版本、分页、损坏恢复、监听、订阅清理和提交通知。

本结果用于验证这组人工数据，不承诺固定容量或延迟。不同文件长度、附件比例、磁盘、系统和 release 构建仍需分别测量；未验证长时间运行的资源变化。
