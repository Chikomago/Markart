## 当前边界

普通插件可用现有 API 开发。独立 Web 界面仍处于收敛阶段，不承诺运行不可信代码时的完整故障或网络隔离。

## 高优先级复核（2026-10-29）

### 网络与导航

当前 CSP 限制 connect-src、img-src、frame-src 等资源通道；sandbox 未开放顶层导航和弹出窗口，但这不能证明 iframe 自身导航受到完整约束。`src-tauri/tauri.conf.json` 的应用 CSP 为 null，也不能作为第二层防线。

不能用覆盖 fetch、隐藏链接或收到 load 后再移除 iframe 来声称已防泄露：导航请求可能已发出。下一阶段应先用不含真实数据的本地测试端点验证脚本导航、链接导航与资源请求，再确定原生导航拦截是否覆盖子框架。必须分 macOS、Windows 验证；失败时维持“仅可信插件”的边界，不扩大隔离承诺。

### 脚本故障

`openWebView()` 的脚本在 iframe 中运行，不在 QuickJS Worker 中。当前没有执行预算或可从宿主可靠中断 iframe 的机制。消息超时、心跳和错误捕获不能抢占阻塞执行；不能据此承诺死循环只影响单个插件。

首先在独立测试窗口和临时数据环境验证失控脚本，不在有未保存文件的实际主窗口中运行破坏性测试。若严格故障隔离是发布条件，需要评估可独立终止的视图运行环境，并验证实际进程隔离；单独创建原生 WebView 不等于已经获得独立进程。

### 实施顺序

1. 保持现有接口，建立不含用户数据的网络和故障验证环境。
2. 先验证原生导航拦截，再决定是否改变 WebView 的承载方式。
3. 将平台实测结论写回文档，未验证能力不标记为已支持。

## 原生导航收敛（2026-10-29）

Windows 本地依赖源码只注册 WebView2 NavigationStarting，未找到子框架事件注册。此平台不能标记为子框架隔离完成。脚本故障隔离也仍未解决。

主程序回归（2026-10-29）：重新编译启动导航策略后，用户确认文件打开与新建窗口均正常。此结果仅确认上述正常交互未受影响，不扩展为 Windows 子框架或故障隔离验证。

## 有界故障实测（2026-10-29）

独立 iframe 运行 750ms 同步计算时，浏览器宿主最大心跳间隔 17ms，macOS 原生宿主为 752ms。macOS 的共享阻塞已复现，不能宣称自定义 WebView 失控时只影响插件。未执行无限循环、内存耗尽或崩溃测试；Windows 未实测。

结论：普通 QuickJS 插件与 DOM 自定义视图必须分别描述故障边界。定时心跳、Promise 超时和 try/catch 都不能抢占 WebKit 当前正在执行的同步脚本。若要求任意自定义界面都不得拖住宿主，应评估独立可终止的运行进程；仅新建 WebView 不构成已验证方案。当前自定义界面限定可信插件，不将“心跳自动关闭”包装成已完成的隔离。

## 独立进程原型（2026-10-29）

macOS 双进程原型实测：计算进程 750ms 同步任务期间，模拟宿主最大心跳间隔 21ms；双方 PID 不同。对照原 iframe 752ms，独立进程是值得采用的后续承载方案。但正式 API 未迁移，不将原型结果描述为当前插件已获得故障隔离。

建议保持 `api.ui.openWebView()` 签名，替换其内部承载。下一阶段依次处理：

1. 宿主启动专用 helper，helper 不注册主程序文件、密钥或任意系统命令；其页面继续使用受限资源加载与导航策略。
2. 使用受控 IPC 代理现有 PluginAPI，所有请求由宿主绑定插件身份、重新检查权限和文件范围；不将原型的本机轮询服务器用于正式通信。
3. 由宿主管理进程和窗口句柄，恢复主题、位置、尺寸、Esc 和点击外部保持打开等既有行为。
4. 关闭视图、停用插件和退出应用时回收进程；通信和退出设置期限，故障只关闭该视图。
5. 分平台验证聚焦、透明区域、缩放、崩溃和进程回收，再替换默认承载。需要验证系统资源耗尽风险，独立进程不等于消除所有系统级影响。

## helper 启动优化（2026-10-29）

基线模拟页冷启动：窗口就绪约 648ms、页面加载约 816ms。增加空白 helper 缓存并用首个业务请求测量实际可响应时间，两轮冷启动为 1155/751ms，缓存路径为 233/198ms。两条路径的 750ms 有界计算用例均保持宿主心跳间隔 21ms。

缓存每个宿主窗口最多一个，60 秒空闲回收；只缓存未运行插件代码的空白进程，实际打开时绑定新的会话与权限代理。已使用的插件进程仍关闭回收，不复用用户页面状态。启用带 HTML 资源的插件时后台预热，不改变 PluginAPI。测量来自独立模拟程序，真实 AI 插件呼出体验需重新编译启动后确认。
