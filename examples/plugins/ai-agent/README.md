# AI 助手

用独立 Web 聚焦搜索式弹窗提问、查找文件和改写当前文件。快捷键为 `Cmd/Ctrl+Shift+A`，也可从顶部功能菜单打开。

## 使用

1. 在偏好设置 → AI 配置填写服务商、API Key、模型与接口地址。
2. 打开 AI 助手，直接输入需求，例如“找一下包含会议记录的文件”或“把当前文件改得简洁一些”。
3. 改写先显示完整预览，点击「应用改写」写入编辑器，可撤销。原文件在生成期间发生变化或切换到其他文件时，不会应用旧结果。

自然语言先由模型识别为提问、查找、列出文件或改写；文件查找本身使用本地索引，按空格分隔的关键词匹配当前目录的文件路径或 SQLite 索引正文，最多展示 50 个结果；点击结果打开文件。索引尚未建立的正文不会参与匹配。

提问会附带当前文件正文（受上下文上限限制）、选区和当前目录最多 200 个文件路径。需要解读其他文件时，会先通过索引定位，或按模型选出的确切文件路径读取正文；最多读取 5 个文件，按上下文总上限分配发送内容，截取时在界面说明。回答上方提供来源文件入口。改写处理当前文件全文，超过上限时提示调整设置，不会截断后覆盖原文。

## 设置

| 设置 | 用途 |
| --- | --- |
| 服务商 | OpenAI、Claude、Ollama |
| API Key | OpenAI 和 Claude 必填，Ollama 可留空 |
| 模型、接口地址 | 支持兼容接口和本机服务 |
| 上下文字符上限 | 默认 24,000，范围 1,000–200,000 |
| 自定义指令 | 回复语言与写作风格 |

普通配置保存在插件存储中；API Key 使用 macOS 钥匙串或 Windows 凭据管理器，按插件隔离。首次启用新版时迁移旧 Key，写入并读回确认后才删除明文配置。安全存储不可用时不会回退到明文。提问与改写会将上述上下文发送给配置的服务商。

## 开发接口

| API | 用途 |
| --- | --- |
| `commands.register`、`ui.registerAction` | 快捷键与顶部菜单入口 |
| `ui.openWebView` | 居中弹窗与结果刷新 |
| `editor.getSnapshot`、`editor.applyEdits` | 读取当前文件、按版本应用改写 |
| `files.view`、`files.list`、`files.open` | 当前目录、文件列表与打开结果 |
| `index.content` | 查询持久化索引正文 |
| `settings.registerCategory/registerControl` | 配置项 |
| `network.request`、`storage`、`clipboard.writeText` | 模型请求、配置与复制 |
| `lifecycle.signal` | 停用后丢弃未完成任务 |

权限在 `manifest.json` 声明。插件只使用宿主 API，不访问 CM6 或原始数据库。网络使用非流式请求，受宿主超时与响应大小限制。

## 构建

```sh
node scripts/build-plugin.mjs examples/plugins/ai-agent
```

在偏好设置 → 插件 → 本地重新导入此目录以更新已安装副本。

## 界面资源

`views/index.html`、`app.js`、`app.css` 使用原生 Web 技术，不依赖宿主组件样式。HTML 通过 `window.markart.request()` 调用文件、索引、编辑器和网络接口。关闭后 iframe 与监听被清理；重新打开不保留临时回复。

输入栏固定在界面底部；预览区向上展开，高度由容器固定。长内容在预览区内部滚动，复制和应用按钮固定在预览区底部。

## 图片

点击输入框的图片按钮，或在 AI 助手内用 Cmd/Ctrl+V 粘贴剪贴板图片，支持 PNG、JPEG、WebP，每次最多 3 张，单张原图最多 15 MB。缩略图可移除；发送后展示在指令下方。原图不写入文件或插件存储。

图片会缩至最长边不超过 1280 像素，并转为 JPEG（透明区域填白）；按宿主 2 MB 请求上限检查总请求大小。发送时把压缩图片交给配置的服务商；需要选择支持图片的模型。OpenAI 使用 image_url，Claude 使用 base64 image，Ollama 使用 images 字段。

可以输入“总结项目计划.md”或“找到会议记录，概括其中的待办”。查找使用索引，解读使用 `files.readText` 读取正文；若读取的是当前打开文件，优先使用编辑器快照中的未保存内容。来源显示在回答上方，点击可打开。
